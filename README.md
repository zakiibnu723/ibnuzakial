# Ibnu Zaki Al — Developer Portfolio

A modern, high-performance personal portfolio website built with **React 19**, **TypeScript**, and **Vite**, featuring Awwwards-inspired dark creative aesthetics and micro-interactions.

## 🚀 Key Highlights
- **Role Positioning**: Fresh Graduate Fullstack Web & Android Developer
- **Featured Works**:
  - **ChestPulse AI**: Chest X-Ray Disease Classifier & Medical Viewer (Hugging Face + PyTorch + FastAPI + React)
  - **VoxMorph Studio**: Voice Transformation & Audio Processing Platform (Hugging Face + FastAPI + Web Audio API)
  - **TaskFlow Mobile**: Offline-First Native Android Task & Habit Tracker (Kotlin, Jetpack Compose, Room SQLite)
  - **OmniCart Commerce**: Fullstack E-Commerce & Management Portal (React, Node.js, PostgreSQL, Prisma)
- **Tech Stack Bento Grid**: Frontend, Backend & Database, Android Kotlin, and Developer Tools / AI Deployment
- **Curriculum Vitae Modal**: ATS-ready 1-page resume with one-click print/PDF export
- **Interactive Micro-Interactions**: Custom magnetic cursor, 60fps particle mesh canvas, and Web Audio API tactile feedback

## 🛠️ Tech Stack
- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailored Modern CSS Design System (Glassmorphism, Neon Accents, CSS Variables)
- **Icons**: Lucide React
- **Audio Effects**: Web Audio API Micro-Synthesizer

## 💻 Local Development
```bash
# Clone the repository
git clone https://github.com/zakiibnu723/ibnuzakial.git

# Navigate into directory
cd ibnuzakial

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
